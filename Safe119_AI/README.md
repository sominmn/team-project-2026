# Safe119 AI

**기상데이터 연계 119 출동 수요 예측과 설명가능한 AI를 통한 구조 자원 효율화 시스템**

공공데이터의 연도 간 정합성 진단, 시도별 월간 구조활동 기록 예측, 설명가능한 AI(XAI), 가상 자원 배분 모의실험을 통합한 연구용 의사결정 지원 프로토타입입니다. 실제 출동 지령 또는 인력·장비 배치 시스템이 아닙니다.

## 1. 연구 목적

- 직전월 기상 정보의 수요 예측 성능 개선 효과 검증
- 연도 간 사고원인 구성 변화와 예측 성능 저하의 관계 진단
- 변화율 예측 및 데이터 변화 신호 기반 선택적 조치의 효과 비교
- SHAP 기반 모델 예측 근거 분석 및 가상 자원 배분 활용 가능성 평가

## 2. 데이터 및 평가 방법

| 항목 | 내용 |
|---|---|
| 구조활동 | 소방청 구조활동현황 공공데이터, 2020~2025년 |
| 기상 | 기상청 종관기상관측(ASOS), 지역별 월 집계 |
| 원본 기록 | 4,221,462행 |
| 지역 결측 제외 | 2,312행 |
| 유효 기록 | 4,219,150행 |
| 집계 단위 | 17개 시도 × 72개월 = 1,224개 |
| 평가 표본 | 2022~2025년, 17개 시도 × 48개월 = 816개 |

각 평가 연도보다 이전 연도의 데이터로 학습하고, 직전월 집계가 예측 시점에 이용 가능하다고 가정합니다. 입력은 직전월·전전월·직전 3개월 평균·전년도 동월 기록과 월 정보이며, 기상 연계 모델에는 직전월 기상 정보를 추가합니다. 기상 결측 대체에는 학습 데이터의 중앙값을 사용합니다.

전월 기록을 그대로 예측값으로 사용하는 기준선과 Ridge, Random Forest(RF), HistGradientBoosting 및 개선 모델을 비교합니다. 주요 평가 지표는 평균 절대오차(MAE)이며, 개선율은 `100 × (1 − 모델 MAE / 기준선 MAE)`입니다. 세부 규칙은 [EVALUATION_V3.md](EVALUATION_V3.md)를 참고하세요.

## 3. 주요 연구 결과

- 직전월 기상 정보를 추가한 RF는 2022~2025년 모두 기상 미포함 RF보다 MAE가 증가했습니다(약 0.87~10.80%).
- 2022년과 2025년에 여러 AI 모델이 기준선보다 낮은 성능을 보였고, 해당 연도에 큰 사고원인 분포 변화(JSD 0.4965, 0.3979)가 함께 관찰되었습니다. 인과관계는 입증하지 않았습니다.
- 2024~2025년 전체 공개 기록은 30.76% 감소했으나 두 연도 공통 16유형은 71.38% 증가했습니다. 6개 연도 공통 9유형의 분포 차이는 작았지만, 해당 집계의 RF는 각 연도의 기준선을 넘지 못했습니다.
- 변화율 RF는 2022~2024년 기준선보다 MAE가 감소했으며, 2025년에는 기준선이 더 우수했습니다. 현재 설계한 변화 신호를 이용한 선택적 조치는 항상 조치하는 방식보다 추가적인 성능 개선을 제공하지 못했습니다(변화율 RF 기준).
- 2025년 기본 RF의 기상 포함·미포함 TreeSHAP 분석에서 전년도 동월 기록의 평균 절대 기여도가 가장 컸습니다. 이는 모델의 예측 근거이며 인과효과가 아닙니다.
- 가상 자원 배분에서는 변화율 RF가 4개 평가 연도 모두 기본 RF보다 배분 불일치가 작았습니다. 전월 기준선 대비 개선은 3개 연도에서 관찰되었습니다.

### 주요 MAE 비교 (전체 공개 기록, 건)

| 평가 연도 | 전월 기준선 | 기본 RF | 기상 포함 RF | 변화율 RF | 변화율 RF의 기준선 대비 개선율 |
|---|---:|---:|---:|---:|---:|
| 2022 | 684.90 | 1,532.68 | 1,546.00 | 463.81 | +32.28% |
| 2023 | 676.11 | 361.85 | 372.36 | 258.44 | +61.78% |

## 5. 설치 및 실행 (대시보드 시연)

저장소의 `Safe119_AI` 폴더에서 실행합니다. Python 가상환경 사용을 권장합니다.

```powershell
python -m pip install -r requirements.txt
python -m pip check
python -m streamlit run app/app.py
```

터미널에 출력된 Local URL(기본 `http://localhost:8501`)로 접속합니다. 포트 충돌 시 다음을 사용합니다.

```powershell
python -m streamlit run app/app.py --server.port 8502
```

대시보드는 Git에 포함된 집계 CSV와 사전 계산 결과를 읽으므로, 화면 시연만 할 경우 원본 데이터 다운로드나 모델 재학습은 필요하지 않습니다.

## 6. 실험 재현 (선택)

아래는 저장된 결과를 다시 계산할 때 실행하는 명령입니다. 기존 결과 파일을 갱신할 수 있으므로 별도 작업 복사본에서 실행하는 것을 권장합니다.

```powershell
python diagnose_v3.py
python evaluate_v3.py
python evaluate_resource_allocation.py
python evaluate_xai_extension.py
```

- `diagnose_v3.py`: 기존 집계 기반 사고원인 대응 후보 및 수록 범위 진단
- `evaluate_v3.py`: 시간순 모델 평가, 기상 효과, 조치 및 위험 신호 평가, 기존 SHAP
- `evaluate_resource_allocation.py`: v3 예측값 기반 가상 자원 배분 평가
- `evaluate_xai_extension.py`: 2025년 기상 포함·미포함 RF 재학습 및 SHAP 검증

원자료 진단을 다시 수행하려면 소방청 연도별 원본을 `data/raw/`에 확보한 뒤 `audit_data_consistency.py`를 실행해야 합니다. 원자료 기반 전처리와 기상 병합은 관련 스크립트를 참고하세요. 원본 자료는 이 저장소에 포함된 집계 자료와 구분됩니다.

추가 XAI 실험의 기록 환경은 [xai_extended_versions.json](reports/v3/xai_extended_versions.json)에서 확인할 수 있습니다. 라이브러리 버전에 따라 재학습 결과가 달라질 수 있습니다.

## 8. 연구 한계

- 사전 고정 기록이 확보되지 않은 후향 평가입니다. 2025년 및 추가 실험은 탐색적 결과로 해석합니다.
- 실제 원본 제공 시점이 확인되지 않아 직전월 집계를 이용할 수 있다고 가정했습니다. 실시간 미래 예측 성능을 검증한 것은 아닙니다.
- 공식 분류 대응표를 확보하지 못해 공통 명칭 선별만 수행했습니다. 수록 범위 변화의 정확한 원인 및 예측 실패의 인과관계는 확정하지 않았습니다.
- SHAP은 기본 RF의 예측 기여도를 설명하며 변화율 RF의 설명이나 인과효과 추정이 아닙니다.
- 가상 자원 배분은 예측 및 실제 공개 기록 비중 간 차이를 비교한 실험입니다. 100점 기준 불일치는 `100 × Σ|예측 배분 비중 − 실제 기록 비중| / 2`로 계산합니다. 실제 인력·장비·이동시간·긴급도·최소 배치 등 제약을 고려하지 않았으므로 현실의 구조 효율 개선을 입증하지 않습니다.
