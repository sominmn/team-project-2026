
# Safe119 AI

공공데이터 기반 119 구조활동 패턴 분석 및
인공지능 구조수요 예측 시스템

## 프로젝트 목표
- 2020~2025년 구조활동 데이터 분석
- 지역별 및 월별 구조활동 패턴 분석
- 머신러닝 기반 구조수요 예측
- Streamlit 대시보드 구현

## 사용 기술
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit

## 폴더 구성
- data: 원본 및 전처리 데이터
- models: AI 모델
- notebooks: 데이터 분석
- reports: 연구 보고서
