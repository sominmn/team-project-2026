# Safe119 v3 평가 규칙

2026-11-27 재현 평가에 적용한 규칙이다. 11월 20일 사전 동결 기록은 저장소에서 확인되지 않았다. 기존 결과가 공개된 뒤 수행한 후향 평가이며 2025년은 탐색 사례다.

- 예측 단위는 시도 × 월이다. 전월, 전전월, 직전 3개월 평균, 작년 동월 건수와 월을 사용한다. 기상은 직전 달 지역 평균을 사용한다. 기상 결측은 해당 연도 이전 학습 행의 중앙값으로 처리한다.
- 2022~2025년 각 평가 연도보다 이른 연도만 학습한다. 전월값 기준선을 동일한 표본에서 평가한다. 개선율은 100 × (1 − 모델 MAE / 기준선 MAE)다. 원본 배포 지연을 확인할 이력은 확보되지 않아 전월 집계가 사용 가능하다고 가정한다.
- 두 위험 지표는 전월 건수의 전전월 대비 절대 변화율과 전년 같은 달 대비 절대 변화율이다. 2022년에는 기존 코드의 30%와 40%를 적용하고, 이후에는 평가 연도보다 이른 2022~2024년 지표의 90백분위수를 기준으로 적용한다. 둘 중 하나라도 해당 기준 이상이면 경보다. 두 값을 모두 계산할 수 없으면 판정을 유보한다.
- 조치는 변화율 예측 후 건수 환산, 최근 2개 연도만 학습, 전월 기준선 전환이다. 각각 동일한 기본 RF와 비교한다. 신호 시 조치는 판정 유보 시 기본 RF를 사용한다.
- 오경보는 경보가 있었으나 해당 조치가 기본 RF 절대오차를 줄이지 못한 경우로 정의한다. 신호와 오차 관계는 시도·연도별 경보율 및 RF의 기준선 초과 MAE로 요약한다. 전국 단위 변화의 영향을 공유하는 지역은 독립 표본으로 볼 수 없다.
- 분류 비교는 공통 이름 유형만 남긴 기존 집계를 사용한다. 원자료 코드북으로 의미가 확인된 대응표는 확보되지 않았다. 전체와 공통 집계의 대상 차이는 각자의 기준선 대비 개선율로 비교한다.
